Introducing MCP

Causal

Aug 29, 2026 • 1 min read

MCP is now available in Causal, connecting your canvases directly to your AI agent. It works with Claude, ChatGPT, Cursor and VS Code.

Instead of pasting context into a prompt or summarising a project by hand, your agent simply reads the canvas. The workspace you are already building becomes the reference material, removing the friction of manual export.

Every element on the board is legible. The agent reads text cards, embedded documents, images and colour values, as well as the connections between them and any other board in your account.

Spatial arrangement is context. Proximity, deliberate placement, visual groupings and directional arrows convey relationships that standard documents flatten out. Causal preserves this structure, giving your agent a genuine understanding of how your ideas relate to one another.

MCP is available today in Causal. Point your agent at an existing board and start working.

Set up MCP in seconds

  1. 1

    Pick your tool

    The steps below change to match it.

  2. 2

    Add a custom connector

    In Claude, open Settings, go to Connectors, and click Add custom connector.

  3. 3

    Paste the address

    Name it Causal, paste this as the URL, and click Add.

    https://app.causal.so/api/mcp
  4. 4

    Authorize

    Click Connect. Sign in to Causal in the window that opens, then click Allow.

  5. 5

    You're set

    Causal is connected. Ask Claude about any board in your account.
