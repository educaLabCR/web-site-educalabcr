# Ideas para transformar

Tres imágenes cuadradas originales para las tarjetas de guías de la portada:

- `ensenar-con-ia-source.png`: cuaderno abierto y red luminosa como metáfora de planificación con IA.
- `ideas-en-materiales-source.png`: notas que se convierten en una composición didáctica visual.
- `tecnologia-educativa-source.png`: puente de vidrio que conecta personas y recursos educativos.

Las escenas comparten vidrio verde esmeralda, papel marfil, luz suave y un acento azul. Se generaron sin texto para conservar la tipografía del sitio en títulos y descripciones. `scripts/educalab-ideas.py` prepara los WebP de 900 × 900 para las guías y actualiza las tres imágenes que usa la portada.
